# 🎄 Allan's Christmas Wishes

A stunning, personalized Christmas wish page featuring animations, music, and a meaningful Bible verse.

## ✨ Features

- **Beautiful Animations**: Falling snowflakes, twinkling stars, and colorful fireworks
- **Responsive Design**: Looks perfect on all devices
- **Background Music**: Christmas music with easy toggle control
- **Bible Verse**: Luke 2:11, 13-14 - celebrating the birth of Christ
- **Personal Touch**: Warm, heartfelt message from Allan
- **Visual Effects**:
  - Glowing text effects
  - Animated backgrounds
  - Floating elements
  - Glass morphism card design
  - Shimmer effects

## 🎵 Music Control

Click the music button in the bottom-right corner to play/pause the background music.

## 🚀 How to Use

Simply open `index.html` in any modern web browser to experience the Christmas magic!

## 🌟 Technologies Used

- Pure HTML5
- CSS3 with advanced animations
- Vanilla JavaScript
- Google Fonts (Great Vibes, Poppins, Playfair Display)
